VERSION CONTROL

Set up Git safely

The strongest Codex workflow combines the Codex desktop app, VS Code with the Codex extension, and Git. Codex provides automation, VS Code keeps work anchored to the repository, and Git provides reviewable, recoverable history.

  1. Install Git for Windows from git-scm.com if the git command is unavailable.
  2. Install VS Code, then install and sign in to the official OpenAI Codex extension.
  3. Open the project folder in VS Code so Codex operates from the correct repository context.
  4. In that folder run git init, then add an appropriate .gitignore before staging files.
  5. Review with git status, then run git add . and git commit -m "initial project snapshot".
  6. Create a private GitHub repository and follow its “push an existing repository” instructions. Never commit secrets or environment files.
